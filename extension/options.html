GHOST-PRIME

Browser bridge settings

Appearance & behavior

Glow the page while Ghost is acting
A soft cyan border lights up whatever tab Ghost is driving, so you can see it working — even on a background tab.
Avoid the “being debugged” banner
Skips Chrome’s debugger so the “Ghost-Prime started debugging this browser” bar never appears. Trade-off: Ghost briefly brings a tab to the front to screenshot it, and can’t type into canvas editors like Google Docs/Slides.

Connection

Host/port/token must match GHOST_BRIDGE_PORT and GHOST_BRIDGE_TOKEN in the app’s .env (defaults 8731 / ghost-local). Open the Ghost-Prime app, then this Chrome connects automatically.
