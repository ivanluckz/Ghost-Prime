Top 7 questions

Short, true answers. Full versions and follow-ups are in qa.md.

1

Chromebooks already have dictation and read-aloud. What’s new?

Those tools type your words or read text aloud, but you still do every step. With Ghost-Prime, one sentence becomes a whole job: it opens the site, searches, reads and explains, or moves files and can undo that. It runs on a school Chromebook with no pay-per-use bill, shows every step, and works alongside those tools, not instead of them.

Tech judges often ask this first. Never say “the first” or “the only one”.

2

How much does it cost to run?

No pay-per-use bills and no servers. Voice and quick answers use Google’s Gemini free tier. Harder jobs use Claude, on a subscription I already had. If its allowance runs out, it pauses and never charges extra. It can also run on the free tier alone (weaker at long jobs; still testing).

3

Is it safe? What if it does something wrong?

It can make mistakes, like any AI. So every step shows live, file changes have undo (“undo that”), and I can limit which websites it opens. PLAN mode only looks and never changes anything, and I don’t use FULL AUTO in public. Not yet: an “Are you sure?” pop-up before big actions. That’s next.

4

Is it private?

Chats, memories and files stay on the Chromebook. Requests go to Anthropic or Google. Voice recordings go to Google unless I use offline voice, and the free tier can use them to improve Google’s products. So: don’t tell it anything private.

5

What did YOU build?

Google and Anthropic make the AI brains. I built everything around them: the app, voice, browser, terminal and file tools, memory, reminders, the brain-picker and the phone app. I designed it, decided what it should do, tested it, and used an AI coding assistant (Claude Code) to write much of the code.

6

Can it work in Kinyarwanda?

Not yet. The app is in English, the offline speech model is English-only, and the offline voice has no Kinyarwanda. Typing in Kinyarwanda might partly work, but I haven’t tested it. It needs Kinyarwanda speech recognition, a Kinyarwanda voice, a translated app, and Kinyarwanda keywords for the brain-picker.

7

Does the phone part work?

Built, not finished. The Android app lets Ghost-Prime see the phone screen as a numbered list and tap, swipe and type. It passes all its tests on a simulated phone, but I haven’t run it on my real Galaxy A05 yet. That’s my next step.

Don’t know? “Good question. I haven’t tested that yet.” Then write it down.
